KG Push · Data Lake

Every metadata/query/skill/target/ABAP artifact generated while dragging on the KG Canvas lives here as a sized droplet, one unique vector ID per entry. Hand-rolled CSS 3D lake (perspective-tilted floor) — drag any droplet down into Embeddings below, or hover one for its ID.

Embeddings

Drag a Datasphere data product droplet in and it auto-names a functional-domain embedding (e.g. KGEMBED_FINANCE01, KGEMBED_SALES01) that groups every vector coordinate already in the lake for that same domain — not just the one you dropped. Or let Lumi auto-propose one per domain.

KG Live — Test Prompts

Prompts below are the real 1:1 Skill + Prompt pairs you generated by dragging query children onto the Joule Node — click to test, or type your own. Each answer shows which vector-store node it resolved against. Bookmark any result to reuse it later.

CJX Live Pilot — 0D_NW_C01

Proof of concept for the hot/cold data design: this hits the real sdadataai-bw-rfc-mcp backend, which pulls actual row data from the SAP demo InfoCube 0D_NW_C01 once, archives it as Parquet, and answers from that archive on repeat queries instead of re-reading BW every time.

KG Errors — Recurring Issues

Issues surfaced during the migration run that keep recurring across objects get pushed here instead of staying buried per-object, with a confidence score and severity — inspired by the production KGABAPCHAIN error/exception model.
